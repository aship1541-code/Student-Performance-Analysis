# Student Performance Data Analysis 📊

## 🚀 Project Overview
This project focuses on analyzing the factors that influence student performance in exams. Using a dataset of student scores, I explored how variables such as parental education, test preparation courses, and gender impact academic outcomes in math, reading, and writing.

## 📊 Dataset Information
The dataset contains information on:
*   **Gender:** Male/Female
*   **Parental Level of Education:** From high school to master's degrees.
*   **Test Preparation Course:** Completed or none.
*   **Scores:** Math, Reading, and Writing scores out of 100.

## 🛠️ Technologies Used
*   **Python** - Core programming language.
*   **Pandas** - Data manipulation and cleaning.
*   **Matplotlib** - Data visualization and plotting.
*   **Jupyter Notebook** - Interactive development environment.

## 📈 Key Insights
After performing Exploratory Data Analysis (EDA), I found:
1.  **Preparation Matters:** Students who completed a test preparation course consistently scored higher across all subjects.
2.  **Parental Influence:** There is a positive correlation between parental education levels and higher student scores.
3.  **Subject Trends:** Female students generally performed better in reading and writing, while math scores showed different distributions.

## 🖼️ Visualizations
The analysis includes:
*   **Histograms** to show score distributions.
*   **Bar Charts** to compare average scores by gender and prep course.
*   **Pie Charts** to visualize the percentage of students based on education levels.
